CHAPTER 03 · COMMUNITY ORIGINS

共同体的起源

从 科学共同体 到 GitHub　——　发光神经元网络背后的制度演化

01
共同体的起源
知识生产者自发形成的协作网络，是开源现象最深层的制度基因。
02
科学共同体：高校、科研机构、企业研究所
以同行评议、公开传播和声誉机制为核心的协作范式，是早期开源协作的模板。
03
互联网扩大了原本的可能性
地理与制度的边界被技术抹平，边际协调成本急剧下降。
04
邮件列表、版本控制、Wiki — 虚拟线上共同体的基石
工具层的选择性演化，塑造了开源协作的组织形态与知识生产方式。
05
GitHub 的崛起：社交属性的现象
代码协作基础设施 + 声誉可视化 + Fork/Merge 博弈机制，催生全球开发者共同体。
06
基金会的崛起 — 融入现有世界的方式
Apache、Linux Foundation 等以法人身份承接知识产权，嵌入主流经济与治理体系。
