OPEN SOURCE VALUES  ·  VALUE SPECTRUM

让代码自己说话

Let the code decide — on values of the open-source culture
  • 01
    技术实用主义至上
    代码质量与可运行性高于任何立场；最好的设计往往由使用场景自然选出。
  • 02
    工程文化的自律
    同行评审、可复现、可追溯——把"信任"替换为"可验证"。
  • 03
    不反对商业化
    许可与变现并存，商业可持续是社区健康的必要条件而非反面。
  • 04
    知识财产权的平衡
    在开放与作者权利之间寻找动态均衡，避免"自由"滑向"无主"。
  • 05
    无限的游戏 · 可持续发展
    目的不是赢，而是让游戏继续下去——社区的生命力优先于一次性胜利。
