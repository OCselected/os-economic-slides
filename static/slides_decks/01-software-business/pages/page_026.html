CASE STUDY · 案例分析
举个例子：Chrome 的数字之旅
1
OPEN SOURCE · 开源内核
Chromium：V8 引擎、ffmpeg 解码器
Google 将浏览器内核开源，V8 提供 JavaScript 执行能力，ffmpeg 提供多媒体解码——大量社区贡献构成基础。
2
FORK & ADD · 闭源封装
Chrome / Edge：Google 与 Microsoft 加入闭源组件
基于 Chromium 添加私有付费版权组件、自动更新服务、数据收集——形成商业差异化，价值增值发生于此。
3
DISTRIBUTION · 编译与分发
官网下载、应用市场：标准化渠道分发
通过 Chrome Web Store、Windows Store 等渠道触达用户——分发基础设施由平台方控制。
4
ACCIDENT · 意外之旅
Google 不能被访问：脱离"正常"渠道
在中国大陆，Chrome 官网无法访问——用户不得不通过第三方镜像、技术论坛、旧版离线包获取，形成非正规分发网络。
5
CONSUMPTION · 消费与成本
谁在消费？谁又在负担成本？
我们每天在 www 上频繁使用——享受开源带来的便利，却鲜少追问：V8 的开发成本、ffmpeg 的维护、分发的基建由谁承担？
