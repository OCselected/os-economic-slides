The Evolution of Code Hosting

EVOLUTION  |  1999 → 2008 → NOW

分布式版本控制系统的社交化跃迁

SVN原子式
集中式版本控制，代码存储于单一服务器，开发者提交至中央仓库——如原子般封闭、确定、线性。
SourceForge  /  Google Code市集初现
开源项目聚合平台，代码以项目为单位陈列。浏览者以"逛市集"的方式发现、下载、使用软件。
GitHub社交基础设施
围绕分布式版本控制系统的社交化平台。用 Web2.0 式的社交 + 逛市集 + 订阅信息的方式获得代码，Fork、Star、Issue 成为新的协作语法。
Kubernetes & Cloud Native舵轮
舵轮象征 Kubernetes 引领云原生技术航向——平台从代码托管走向运行编排，从市集走向港口。
CLOUD NATIVE · 舵
K8S
舵 轮  ·  THE RUDDER 舵轮象征 Kubernetes 引领云原生技术航向。平台不仅是代码的容器，更是协作秩序的导航仪——在无序的信息之海中锚定方向。
CORE INSIGHT  ·  核心洞见

平台是连接者，
有序信息是隐藏的价值

平台有着重要的连接作用，分析代码是隐藏在背后的价值——将无序的协作行为编码为可被检索、可被追溯、可被信任的有序信息资产。
