开源定义
The Open Source Definition
— A Bell Tolls for the Open Source Revolution —
01自由再分发：许可证不得限制任何人因任何原因向任何人出售或赠送软件。Free Redistribution
02源代码：程序必须附带源代码，并允许以源代码和可执行形式分发。Source Code Must Be Provided
03衍生作品：许可证必须允许修改版本，并受与原始软件相同的条款约束。Derived Works
04作者源代码完整性：许可证可要求衍生作品以不同名称或版本号发布。Integrity of the Author's Source
05不歧视个人或群体：许可证不得限制任何人或特定群体参与。No Discrimination Against Persons
06不歧视任何领域：许可证不得限制软件用于特定领域，如商业或学术研究。No Discrimination Against Fields
07分发许可：软件衍生作品的许可必须随软件一同分发，不得单独授权。License of Derived Works
08不针对特定产品：许可证不得要求软件仅属于某一特定产品组合。License Not Product-Specific
09不限制其他软件：许可证不得对其他随开源软件分发的软件强加额外限制。License Must Not Restrict Other Software
10技术中立：许可证不得依赖任何特定技术、接口或编程风格。License Must Be Technology-Neutral
