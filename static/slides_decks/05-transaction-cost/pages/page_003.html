Coase · Williamson · Path Dependence
FOUR QUESTIONS
Ⅰ
科斯的追问：为什么有些协作通过市场完成，有些通过企业组织？制度的边界由什么决定？
Ⅱ
第三种答案：开源给出了超越"市场—企业"二元对立的协作形态——通过互联网的虚拟共同体实现跨组织生产。
Ⅲ
路径依赖：技术不是被发明的，而是被累积、被建构的。既有协议、许可证、工具链构成不可逆的制度轨道。
Ⅳ
Williamson L1 · 社会嵌入：开源协作规范嵌入文化层面，通过共享信念与声誉机制，降低了一笔笔交易的协调成本。
